
# Setup Guide: Complete Installation

## Step 1: Environment Setup
1. Clone repository
2. Create virtual environment
3. Install Python dependencies

## Step 2: Database Configuration
1. Create Supabase account
2. Run `database_setup.sql`
3. Import your assessment data
4. Configure connection in `secrets.toml`

## Step 3: API Setup (Optional)
1. Get OpenRouter API key
2. Configure in `secrets.toml`
3. Test AI integration

## Step 4: Data Preparation
1. Run Phase 1 analysis
2. Validate success scores
3. Import results to database

## Step 5: Launch Application
1. Start Streamlit app
2. Verify database connection
3. Test all features

## Troubleshooting
- Database connection issues
- API key configuration
- Data format validation
